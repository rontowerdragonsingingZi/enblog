Read the screen. Leave the translation there.

What it does

A desktop loop for text that is already on screen: capture, read, translate, pin.

Free region

A full-screen mask and a drag selection. The default hotkey is Ctrl + Shift + T.

Local OCR

Tesseract runs on the machine. The Windows installer bundles it, so OCR does not need a separate setup.

Floating card

Screenshot, source, and translation stay in a card you can drag, resize, copy, or close.

Two engines

Google Translate by default, or a LibreTranslate URL you set yourself.

Tray and startup

Hide to the system tray and start with Windows, macOS, or Linux.

One instance

A second launch focuses the window that is already running. Reinstalling upgrades in place.

Four moves

Summon

Press the hotkey, or use the tray menu.

Select

Drag across the text you want read.

Wait

OCR runs locally, then the chosen engine translates.

Keep

Move the card. Copy either side. Close it when done.
