Guide

  1. Start the app. You can hide it to the tray after launch.
  2. Set the source and target languages.
  3. Press Ctrl + Shift + T. The shortcut can be changed.
  4. Drag a rectangle around the text.
  5. Wait for OCR and translation.
  6. Drag the card by its title. Resize from the corner. Copy the translation or the source. Close the card, or click empty space to hide to the tray.

OCR

Recognition uses local Tesseract only. The Windows installer already includes it. On macOS and Linux, install Tesseract and the language data you need, such as English plus Simplified Chinese. If it is missing, capture will tell you.

Translation

Google Translate is the default. You can point the app at your own LibreTranslate URL instead. Recognized text is sent to whichever engine you select. The screenshot itself stays on the machine.

Permissions

Windows may ask for screen capture the first time. macOS needs Screen Recording and Accessibility for the global hotkey. Android does not offer the same tray and global hotkey model; use the in-app capture action there.
