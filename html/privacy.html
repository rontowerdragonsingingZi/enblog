Privacy

Updated 2 October 2026.

The app

There is no account. Settings stay on the device. OCR uses local Tesseract and does not send the screenshot to an OCR service.

Translation is different. If Google Translate is selected, the recognized text is sent to Google. If you set a LibreTranslate URL, that text is sent to the server you named. Pick the engine with that in mind.

The floating card, including its screenshot, remains local. Startup registration only writes a login item on desktop systems that support it.

This website

The site is static. It has no forms, accounts, or analytics scripts. Fonts are loaded from Google Fonts, so a visit can contact that service. Download buttons leave this site and open GitHub Releases.
