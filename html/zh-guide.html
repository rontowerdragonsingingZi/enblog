使用

  1. 启动应用。可以在启动后收进托盘。
  2. 设置源语言和目标语言。
  3. 按 Ctrl + Shift + T。快捷键可以改。
  4. 拖出一个矩形，框住要识别的文字。
  5. 等待 OCR 和翻译。
  6. 拖标题栏移动卡片，从角落调整大小。复制译文或原文。关闭卡片，或点空白处收进托盘。

OCR

识别只用本机 Tesseract。Windows 安装包已经带上。macOS 和 Linux 需要自行安装 Tesseract 及语言包，例如英语加简体中文。没装时，截屏会提示你。

翻译

默认使用 Google 翻译。也可以填自己的 LibreTranslate 地址。识别出的文字会发给所选引擎。截图本身留在本机。

权限

Windows 第一次截屏时可能会请求屏幕捕获权限。macOS 需要屏幕录制和辅助功能，才能使用全局快捷键。Android 没有同样的托盘和全局快捷键，请用应用内的截屏操作。
